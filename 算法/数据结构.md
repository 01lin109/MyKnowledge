# 1.差分
## 1. 核心原理：什么是差分？

差分数组 $D$ 的定义非常简单：**它是原数组 $A$ 中相邻元素的差值。**

假设原数组为 $A = [a_0, a_1, a_2, a_3, \dots]$，那么差分数组 $D$ 的对应关系如下：

- $D[0] = A[0]$
    
- $D[i] = A[i] - A[i-1]$ （当 $i > 0$ 时）
    

### 关键特性：前缀和还原

差分和**前缀和**互为逆运算。如果你对差分数组 $D$ 求前缀和，就能奇迹般地还原出原数组 $A$！

$$A[i] = \sum_{j=0}^{i} D[j]$$

### 区间修改的神奇操作

如果你想把原数组 $A$ 在区间 `[left, right]` 上的所有元素都加上一个值 `val`：

- 你只需要让 **$D[left] += val$**（这会导致从 `left` 开始往后的所有元素在求前缀和时都加上 `val`）
    
- 再让 **$D[right + 1] -= val$**（这会把 `right` 之后的多余加分“扣掉”）
    

## 2. 具体示例

我们来看一个具体的账本修改例子。

假设原数组 $A = [2, 5, 1, 6, 8]$。

1. **构造差分数组 $D$**：
    
    - $D[0] = 2$
        
    - $D[1] = 5 - 2 = 3$
        
    - $D[2] = 1 - 5 = -4$
        
    - $D[3] = 6 - 1 = 5$
        
    - $D[4] = 8 - 6 = 2$
        
    - 此时 $D = [2, 3, -4, 5, 2]$。
        
2. **进行区间修改**：我们想把区间 `[1, 3]`（即 5, 1, 6 这三个数）都**加上 3**。
    
    - `left = 1`, `right = 3`, `val = 3`
        
    - $D[1] += 3 \implies 3 + 3 = 6$
        
    - $D[3 + 1] -= 3 \implies D[4] = 2 - 3 = -1$
        
    - 修改后的差分数组 $D = [2, \mathbf{6}, -4, 5, \mathbf{-1}]$。
        
3. **还原原数组**：对新的 $D$ 求前缀和：
    
    - $A'[0] = 2$
        
    - $A'[1] = 2 + 6 = 8$
        
    - $A'[2] = 8 + (-4) = 4$
        
    - $A'[3] = 4 + 5 = 9$
        
    - $A'[4] = 9 + (-1) = 8$
        
    - 最终得到 $A' = [2, 8, 4, 9, 8]$。对比原数组，发现中间三个数确实都加上了 3！
        

## 3. Java 代码实现

下面是一个完整的工具类实现，封装了差分算法的核心逻辑。

Java

```
public class DifferenceArray {
    // 差分数组
    private int[] diff;

    /* 输入一个初始数组，区间操作将在这个数组上进行 */
    public DifferenceArray(int[] nums) {
        int n = nums.length;
        diff = new int[n];
        
        // 构造差分数组
        diff[0] = nums[0];
        for (int i = 1; i < n; i++) {
            diff[i] = nums[i] - nums[i - 1];
        }
    }

    /* 给闭区间 [left, right] 增加 val（val 可为负数）*/
    public void increment(int left, int right, int val) {
        diff[left] += val;
        // 如果 right + 1 超过数组长度，说明修改延伸到了数组末尾，不需要再扣减
        if (right + 1 < diff.length) {
            diff[right + 1] -= val;
        }
    }

    /* 返回结果数组（通过前缀和复原） */
    public int[] result() {
        int[] res = new int[diff.length];
        // 根据差分数组构造结果数组
        res[0] = diff[0];
        for (int i = 1; i < diff.length; i++) {
            res[i] = res[i - 1] + diff[i];
        }
        return res;
    }

    // 测试一下
    public static void main(String[] args) {
        int[] nums = {2, 5, 1, 6, 8};
        
        // 初始化差分工具类
        DifferenceArray df = new DifferenceArray(nums);
        
        // 执行区间修改：将下标 1 到 3 的元素都加 3
        df.increment(1, 3, 3);
        
        // 如果还有其他修改，可以继续调用，比如将 0 到 2 的元素减 1
        // df.increment(0, 2, -1); 
        
        // 获得最终结果
        int[] result = df.result();
        
        // 打印输出：[2, 8, 4, 9, 8]
        System.out.print("最终数组: ");
        for (int x : result) {
            System.out.print(x + " ");
        }
    }
}
```

## 4. 什么时候用差分？

- **唯一适用场景**：只涉及**区间批量修改**，且在所有修改完成之后，才需要查询数组的值。
    
- **注意**：如果题目要求“边修改边查询”（比如改一次，查一次），差分就不合适了，因为每次还原都需要 $O(N)$。那种情况需要请出更高级的数据结构——**线段树（Segment Tree）**或**树状数组（Binary Indexed Tree）**。

# 2.前缀和（二维）
二维前缀和的构造原理和一维是一样的（都是为了实现 $O(1)$ 的区域查询），但因为**维度升级到了面**，它的递推公式会稍微复杂一点。

如果直接照搬一维“一个接一个累加”的想法，在二维矩阵里会变得很难写。二维前缀和最合理、最优雅的构造方式是利用**容斥原理（Inclusion-Exclusion Principle）**。

为了让代码写起来最舒服，业界有一个公认的**最佳实践：把前缀和矩阵的行列各放大 1 格，从下标 1 开始算。**

## 1. 为什么要从下标 1 开始（最合理的避坑指南）

假设原矩阵为 `matrix`，前缀和矩阵为 `sum`。

我们定义 `sum[i][j]` 表示：**从矩阵左上角 `(0, 0)` 到右下角 `(i-1, j-1)` 这个矩形区域内所有元素的总和。**

> **为什么不直接对应 `(i, j)`？**
> 
> 如果 `sum[i][j]` 对应 `(i, j)`，那么当你在算第一行或第一列（即 `i=0` 或 `j=0`）时，公式里会出现 `i-1` 或 `j-1`，导致**数组越界**。你就必须写一堆 `if-else` 来特判边界。
> 
> 把 `sum` 矩阵的长宽都增加 1，让 `sum[0][x]` 和 `sum[x][0]` 都默认等于 0，就能完美**免去所有边界判断**！

## 2. 核心构造原理：容斥原理

我们要计算 `sum[i][j]`，它由四个部分组成：

1. **`sum[i-1][j]`**：上方大矩形的总和。
    
2. **`sum[i][j-1]`**：左边大矩形的总和。
    
3. **`matrix[i-1][j-1]`**：当前格子的原数值（注意，因为 `sum` 索引偏移了 1，所以对应 `matrix` 的 `i-1` 和 `j-1`）。
    
4. **`sum[i-1][j-1]`**：左上角被重复加了两次的重叠区域。
    

**最合理的构造公式：**

$$\text{sum}[i][j] = \text{sum}[i-1][j] + \text{sum}[i][j-1] - \text{sum}[i-1][j-1] + \text{matrix}[i-1][j-1]$$

_(加了上方和左边，减去重复的左上角，最后加上当前格)_

## 3. Java 代码的最佳实践

按照上述逻辑，写出来的构造代码极其干净：

Java

```
public class MatrixPrefixSum {
    private long[][] sum;

    public MatrixPrefixSum(int[][] matrix) {
        if (matrix == null || matrix.length == 0 || matrix[0].length == 0) return;
        
        int m = matrix.length;
        int n = matrix[0].length;
        
        // 关键：长宽各多开辟 1 格，初始值全为 0
        sum = new long[m + 1][n + 1];
        
        // 极其丝滑的循环，完全不需要担心 i-1 或 j-1 越界
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                sum[i][j] = sum[i - 1][j] 
                          + sum[i][j - 1] 
                          - sum[i - 1][j - 1] 
                          + matrix[i - 1][j - 1]; // 注意 matrix 要减 1
            }
        }
    }
}
```

## 4. 构造出来后，如何 $O(1)$ 查询任意子矩阵？

既然构造时多留了一格边界，查询时也同样爽快。

如果你想查询原矩阵中，左上角为 `(r1, c1)`，右下角为 `(r2, c2)` 的矩形区域和（这里 `r` 和 `c` 是原矩阵的 0 设基准下标）：

由于 `sum` 矩阵整体往右下偏移了一格，原矩阵的 `(r2, c2)` 对应 `sum` 的 `(r2 + 1, c2 + 1)`。

**查询公式同样基于容斥原理：**

Java

```
public long queryRange(int r1, int c1, int r2, int c2) {
    // 转换为 sum 矩阵对应的下标
    return sum[r2 + 1][c2 + 1] 
         - sum[r1][c2 + 1] 
         - sum[r2 + 1][c1] 
         + sum[r1][c1];
}
```
