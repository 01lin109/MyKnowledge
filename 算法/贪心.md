### 2.1摆动序列：
https://leetcode.cn/problems/wiggle-subsequence/description/
如果连续数字之间的差严格地在正数和负数之间交替，则数字序列称为 **摆动序列 。**第一个差（如果存在的话）可能是正数或负数。仅有一个元素或者含两个不等元素的序列也视作摆动序列。

- 例如， `[1, 7, 4, 9, 2, 5]` 是一个 **摆动序列** ，因为差值 `(6, -3, 5, -7, 3)` 是正负交替出现的。
    
- 相反，`[1, 4, 7, 2, 5]` 和 `[1, 7, 4, 5, 5]` 不是摆动序列，第一个序列是因为它的前两个差值都是正数，第二个序列是因为它的最后一个差值为零。

**子序列** 可以通过从原始序列中删除一些（也可以不删除）元素来获得，剩下的元素保持其原始顺序。

给你一个整数数组 `nums` ，返回 `nums` 中作为 **摆动序列** 的 **最长子序列的长度** 。

```java
public static int wiggleMaxLength(int[] nums) {  
    int n = nums.length;  
    if (n < 2) return n;  
  
    int[] dp = new int[n];  
    dp[0] = 1;  
  
    int prevDiff = 0; // 上一次差值  
    int ans = 1;  
  
    for (int i = 1; i < n; i++) {  
        int diff = nums[i] - nums[i - 1];  
        if ((diff > 0 && prevDiff <= 0) || (diff < 0 && prevDiff >= 0)) {  
            ans++;  
            prevDiff = diff; // 更新上一次差值  
        }  
        // 否则不增加长度  
    }  
  
    return ans;  
}
```
### 2.2最大子数组和
给你一个整数数组 `nums` ，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。
https://leetcode.cn/problems/maximum-subarray/submissions/714528190/
**子数组**是数组中的一个连续部分。
```java
class Solution {  
    public int maxSubArray(int[] nums) {  
        // 初始值不能设为 0 或 -1，必须设为数组第一个元素，以应对全负数情况  
        int maxSoFar = nums[0];  
        int currentSum = nums[0];  
  
        for (int i = 1; i < nums.length; i++) {  
            // 核心逻辑：如果当前和是负数，丢掉它，换成当前的数字  
            // 相当于：currentSum = Math.max(nums[i], currentSum + nums[i]);            if (currentSum < 0) {  
                currentSum = nums[i];  
            } else {  
                currentSum += nums[i];  
            }  
  
            // 维护全局最大值  
            if (currentSum > maxSoFar) {  
                maxSoFar = currentSum;  
            }  
        }  
        return maxSoFar;  
    }  
}
```

## 2.3分发糖果 （局部最优-》全局最优）
https://leetcode.cn/problems/candy/
- 一次是从左到右遍历，只比较右边孩子评分比左边大的情况。
- 一次是从右到左遍历，只比较左边孩子评分比右边大的情况。
```java
class Solution {
    /**
         分两个阶段
         1、起点下标1 从左往右，只要 右边 比 左边 大，右边的糖果=左边 + 1
         2、起点下标 ratings.length - 2 从右往左， 只要左边 比 右边 大，此时 左边的糖果应该 取本身的糖果数（符合比它左边大） 和 右边糖果数 + 1 二者的最大值，这样才符合 它比它左边的大，也比它右边大
    */
    public int candy(int[] ratings) {
        int len = ratings.length;
        int[] candyVec = new int[len];
        candyVec[0] = 1;
        for (int i = 1; i < len; i++) {
            candyVec[i] = (ratings[i] > ratings[i - 1]) ? candyVec[i - 1] + 1 : 1;
        }

        for (int i = len - 2; i >= 0; i--) {
            if (ratings[i] > ratings[i + 1]) {
                candyVec[i] = Math.max(candyVec[i], candyVec[i + 1] + 1);
            }
        }

        int ans = 0;
        for (int num : candyVec) {
            ans += num;
        }
        return ans;
    }
}
```

## 2.4根据身高重建队列
https://leetcode.cn/problems/queue-reconstruction-by-height/description/
```java
public static int[][] reconstructQueue(int[][] people) {  
    Arrays.sort(people, (a, b) -> {  
        if (a[0] == b[0]) return a[1] - b[1];   
        return b[0] - a[0];  
    });  
    LinkedList<int[]> que = new LinkedList<>();  
    for (int[] p : people) {  
        que.add(p[1],p);  
    }  
    return que.toArray(new int[people.length][]);  
}
```
**重点**LinkedList的使用以及排序
核心思想：两个维度，A：前面有k个人 B：身高
选按身高维度去考虑：因为按K无法考虑
从高到低排序，身高一样就按k从小到大
依次插入即可

## 2.5用最少的剑打爆气球
https://leetcode.cn/problems/minimum-number-of-arrows-to-burst-balloons/description/
**遇到的小坑**
整数溢出
在刷区间类算法题时，遇到接近 int 临界值（如 2147483647）的测试用例时，极易触发以下经典大坑：

### 🚨 核心大坑：自定义排序中的“整数溢出”

- **错误写法**：
    
    Arrays.sort(points, (a, b) -> a[0] - b[0]);
    
- **致命原因**：
    
    当一个极大的正数减去一个极小的负数（例如 $2147483646 - (-2147483646)$），结果会超出 int 的最大范围。在底层二进制运算中，这会导致**正负号反转（溢出绕回）**。原本应该返回正数的减法变成了负数，导致排序结果彻底颠倒，贪心策略直接失效。
    

### 💡 黄金解决方案

在编写任何自定义 Comparator 时，**永远不要用减法来代替大小比较**。请改用以下两种安全写法：

Java 内部使用 if-else 实现了安全的数值比较，绝对不会发生溢出。

```java
// 安全的升序排序
Arrays.sort(points, (a, b) -> Integer.compare(a[0], b[0]));
```

> **🔥 警报标志**：以后只要在题目输入或测试用例中看到 2147483647 或 -2147483648，脑子里要立刻拉响“**严禁使用减法做比较器**”的警报。
