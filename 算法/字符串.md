# 📝 KMP 算法笔记整理（Java）

## 1️⃣ KMP 算法概念

- KMP（Knuth-Morris-Pratt）算法用于在 **文本字符串**中高效查找 **模式字符串**。
- 核心思想：
    - 遇到不匹配时，**不回退文本指针**
    - 利用 **模式自身的重复信息（前缀表 / next 数组）** 跳转模式指针
- 时间复杂度：O(n + m)
    - n = 文本长度
    - m = 模式长度

---

## 2️⃣ next 数组（前缀表 / LPS）概念

- next[i] = **pattern[0..i] 的最长相等前后缀长度**
- 前缀：不包含最后一个字符的开头子串
- 后缀：不包含第一个字符的结尾子串
- 作用：失配时告诉模式指针 **下次从哪里开始匹配**

---

## 3️⃣ 构建 next 数组 Java 代码

```java
public class KMP {

    /**
     * 构建 next 数组（前缀表 / LPS 数组）
     * @param pattern 模式字符串
     * @return next 数组
     */
    public static int[] buildNext(String pattern) {
        int m = pattern.length();
        int[] next = new int[m];
        next[0] = 0; // 第一个字符最长前后缀长度为 0
        int len = 0; // 当前最长相等前后缀长度

        for (int i = 1; i < m; i++) {
            // 不匹配时回退 len
            while (len > 0 && pattern.charAt(i) != pattern.charAt(len)) {
                len = next[len - 1];
            }
            // 匹配时，len 加 1
            if (pattern.charAt(i) == pattern.charAt(len)) {
                len++;
            }
            next[i] = len;
        }
        return next;
    }
}
```

## 4️⃣ KMP 匹配函数 Java 代码

```java
public class KMP {

    /**
     * KMP 查找模式串在文本串中的起始位置
     * @param text 文本字符串
     * @param pattern 模式字符串
     * @return 匹配起始索引，未匹配返回 -1
     */
    public static int kmpSearch(String text, String pattern) {
        if (pattern.isEmpty()) return 0;

        int n = text.length();
        int m = pattern.length();
        int[] next = buildNext(pattern);

        int j = 0; // 模式指针
        for (int i = 0; i < n; i++) {
            // 不匹配时，模式指针跳转
            while (j > 0 && text.charAt(i) != pattern.charAt(j)) {
                j = next[j - 1];
            }
            // 匹配则同时推进模式指针
            if (text.charAt(i) == pattern.charAt(j)) {
                j++;
            }
            // 匹配完成
            if (j == m) {
                return i - m + 1;
            }
        }
        return -1;
    }

    // 测试示例
    public static void main(String[] args) {
        String text = "ababcabcacbab";
        String pattern = "abcac";
        int index = kmpSearch(text, pattern);
        System.out.println("匹配起始位置: " + index); // 输出 5
    }
}
```

## 5️⃣ 使用提示

1. 构建 next 数组只需要模式串一次
2. 匹配时文本串指针 **永远不回退**
3. next 数组帮助模式指针快速跳转，节省比较次数
4. next 数组 = 前缀表（LPS 数组），语义相同
