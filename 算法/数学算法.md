# 2.快速幂
![[PixPin_2026-05-29_20-32-18.png]]

## 📌 核心思路：二进制拆分（快速幂）

直接连乘 $b$ 次会超时（时间复杂度 $O(b)$）。快速幂的核心思想是**将指数 $b$ 拆分为二进制表示**，从而将时间复杂度降到 $O(\log b)$。

以计算 $a^{13}$ 为例，13 的二进制是 $(1101)_2 = 8 + 4 + 0 + 1$：

$$a^{13} = a^8 \times a^4 \times a^1$$

在循环中，底数 $a$ 每一轮都在默默执行**自我平方**（$a^1 \to a^2 \to a^4 \to a^8 \dots$）。

我们通过位运算 `b & 1` 检查 $b$ 的二进制最低位：

- 如果是 `1`，说明需要这一项，就把它累乘到答案 `ans` 中。
    
- 无论是不是 `1`，底数 $a$ 都继续平方，并将 $b$ 右移一位（`b >>= 1`）继续检查下一位。
    

## 📐 数学原理支撑：同余定理

为什么可以在计算的每一步都对 `p` 取模？因为模运算满足**同余定理的乘法分配律**：

$$(A \times B) \bmod p = ((A \bmod p) \times (B \bmod p)) \bmod p$$

- **为什么要一直取模？** 因为当 $a, b \le 10^9$ 时，$a^b$ 是一个无法想象的天文数字，计算机根本存不下，会发生**整型溢出**。
    
- **一直取模的妙处**：
    
    在每一步乘法后立刻 `% p`，既不影响最终的正确结果，又能将中间计算结果死死限制在 `long` 类型的安全范围内（最大约 $10^{18}$），防止被挤爆。
    

## 🛠️ 完整 Java 代码实现

代码中使用了 `BufferedReader` 进行输入优化，以应对 $T \le 2 \times 10^5$ 的大数据量。

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();
        StringTokenizer st;

        String line = br.readLine();
        if (line == null) return;
        int t = Integer.parseInt(line.trim());

        while (t-- > 0) {
            st = new StringTokenizer(br.readLine());
            long a = Long.parseLong(st.nextToken());
            long b = Long.parseLong(st.nextToken());
            long p = Long.parseLong(st.nextToken());

            sb.append(fastPower(a, b, p)).append("\n");
        }
        System.out.print(sb.toString());
    }

    private static long fastPower(long a, long b, long p) {
        if (p == 1) return 0; // 特判：任何数模 1 均为 0

        long ans = 1;
        a = a % p; // 预先取模，防止 a 自身过大

        while (b > 0) {
            if ((b & 1) == 1) {       // 若当前二进制位是 1
                ans = (ans * a) % p;  // 累乘并立即取模防溢出
            }
            a = (a * a) % p;          // 底数倍增 (a^1 -> a^2 -> a^4...)
            b >>= 1;                  // 指数右移一位
        }
        return ans;
    }
}

# 3.分数取模
## 📌 题目核心描述

对于给定的 $t$ 组数据，每组包含两个整数 $a$ 和 $b$，计算 $\frac{a}{b} \bmod P$ 的值。

- **模数**：$P = 10^9 + 7$（一个大质数）。
    
- **数据范围**：$t \le 10^4$，$-10^9 \le a \le 10^9$，$1 \le b \le 10^9$。
    

## 📐 数学原理公式支撑

在模运算中，由于不能直接进行除法，我们需要通过**乘法逆元**将除法转化为乘法。

### 1. 转化公式

设 $b$ 的乘法逆元为 $b^{-1}$（即在模 $P$ 意义下，乘以 $b^{-1}$ 的效果等于除以 $b$），则有：

$$\left(\frac{a}{b}\right) \bmod P = (a \times b^{-1}) \bmod P$$

### 2. 费马小定理（求逆元）

因为题目明确指出 $P$ 是一个**质数**，且 $b \le 10^9$ 绝不是 $P$ 的倍数，根据**费马小定理**：

$$b^{P-1} \equiv 1 \pmod P \implies b \times b^{P-2} \equiv 1 \pmod P$$

由此得出，$b$ 的逆元就是：

$$b^{-1} = b^{P-2} \bmod P$$

### 3. 最终计算公式

将逆元代入原式，我们真正要计算的终极公式为：

$$\left(\frac{a}{b}\right) \bmod P = (a \times b^{P-2}) \bmod P$$

## 💡 算法实现思路与“三大坑点”

1. **快速幂求逆元**：指数 $P-2 = 10^9+5$ 非常大，必须使用 **$O(\log P)$ 的快速幂** 算法来计算 $b^{P-2} \bmod P$。
    
2. **处理负数分子（核心大坑）**：题目中 $a$ 的范围包含负数（$-10^9 \le a$）。在 Java 中，对负数取模（如 `-5 % 7`）会得到负数（`-5`）。为了保证结果在 $[0, P-1]$ 之间，必须使用标准的**负数转正公式**：
    
    $$a = (a \bmod P + P) \bmod P$$
    
3. **防止整型溢出**：$a$ 和逆元都接近 $10^9$，两者相乘会达到 $10^{18}$，必须全程使用 `long` 进行计算并在相乘后立刻 `% P`。
    

## 🛠️ 完整 Java 代码实现

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

public class Main {
    // 定义全局大质数 P
    private static final long P = 1000000007L;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();
        StringTokenizer st;

        String line = br.readLine();
        if (line == null) return;
        int t = Integer.parseInt(line.trim());

        while (t-- > 0) {
            st = new StringTokenizer(br.readLine());
            long a = Long.parseLong(st.nextToken());
            long b = Long.parseLong(st.nextToken());

            // 1. 处理负数分子的取模问题，使其安全变为 [0, P-1] 之间的正整数
            a = (a % P + P) % P;

            // 2. 利用费马小定理，通过快速幂计算分母 b 的逆元： b^(P-2) % P
            long inv = fastPower(b, P - 2);

            // 3. 将除法转化为乘法并输出结果
            long ans = (a * inv) % P;
            sb.append(ans).append("\n");
        }
        System.out.print(sb.toString());
    }

    /**
     * 标准快速幂：计算 (base^exp) % P
     */
    private static long fastPower(long base, long exp) {
        long ans = 1;
        base = base % P;
        while (exp > 0) {
            if ((exp & 1) == 1) {
                ans = (ans * base) % P;
            }
            base = (base * base) % P;
            exp >>= 1;
        }
        return ans;
    }
}
