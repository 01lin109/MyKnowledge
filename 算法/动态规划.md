# 1.01背包（恰好装满 && 不要求装满）
![[PixPin_2026-06-08_20-48-17.png]]
```java
import java.io.BufferedReader;

import java.io.InputStreamReader;

import java.util.Arrays;

import java.util.StringTokenizer;

  

public class Main {

    private static final int INF = 0x3f3f3f3f; // 设定一个安全的负无穷

  

    public static void main(String[] args) throws Exception {

        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        StringTokenizer st = new StringTokenizer(br.readLine());

  

        int n = Integer.parseInt(st.nextToken());

        int V = Integer.parseInt(st.nextToken());

  

        // 为了方便对应物品编号，行开辟 n + 1，列开辟 V + 1

        int[][] dp1 = new int[n + 1][V + 1];

        int[][] dp2 = new int[n + 1][V + 1];

  

        // =================【方案 1 初始化】=================

        // 默认全为 0，Java 已经帮我们做好了

  

        // =================【方案 2 初始化】=================

        // i = 0 时，除了 j = 0 以外，其余全部设为不可达

        dp2[0][0] = 0;

        for (int j = 1; j <= V; j++) {

            dp2[0][j] = -INF;

        }

  

        // ================= 状态转移 =================

        for (int i = 1; i <= n; i++) {

            st = new StringTokenizer(br.readLine());

            int v = Integer.parseInt(st.nextToken()); // 体积

            int w = Integer.parseInt(st.nextToken()); // 价值

  

            for (int j = 0; j <= V; j++) {

                // 情况 A：不选第 i 件物品

                dp1[i][j] = dp1[i - 1][j];

                dp2[i][j] = dp2[i - 1][j];

  

                // 情况 B：选第 i 件物品（必须装得下）

                if (j >= v) {

                    // 方案 1 正常更新

                    dp1[i][j] = Math.max(dp1[i][j], dp1[i - 1][j - v] + w);

  

                    // 方案 2 更新：只有当前驱状态不是 -INF 时，转移才有意义

                    if (dp2[i - 1][j - v] != -INF) {

                        dp2[i][j] = Math.max(dp2[i][j], dp2[i - 1][j - v] + w);

                    }

                }

            }

        }

  

        // ================= 输出结果 =================

        // 方案 1 的答案：前 n 件物品，容量为 V 的最大值

        System.out.println(dp1[n][V]);

  

        // 方案 2 的答案：如果是负数，说明不合法（无法恰好装满），输出 0

        if (dp2[n][V] < 0) {

            System.out.println(0);

        } else {

            System.out.println(dp2[n][V]);

        }

    }

}
```

**核心区别：要求恰好装满同样的遍历只需要把物品体积之和不等于背包容量的初始化为负无穷就行（不可达）**
