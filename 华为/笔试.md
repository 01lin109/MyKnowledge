### 1、双十一凑单与优惠券最优组合

双十一期间，小明准备购买一些商品。他有 $n$ 件必须买的商品，还有 $m$ 件可选的凑单商品。此外，他获得了 $k$ 张优惠券，每张优惠券有类型（满减或折扣）和使用门槛。请你帮助小明计算，他最少需要支付多少钱。
#### 规则说明：
1. **商品购买：**
    - 必须买的商品必须全部购买。
    - 可选商品可以自由选择是否加入购物车（每件最多选一次）。
2. **优惠券使用：**
    - 每张优惠券最多使用一次，且可以任意决定是否使用。
    - 使用顺序可以任意决定，你需要找到最优顺序使得最终支付最小。
    - 每张优惠券有一个使用门槛 `threshold`（正整数），表示在应用该优惠券之前的当前订单总价必须 $\ge \text{threshold}$ 才能使用。
3. **优惠券类型：**
    - `type = 0`：满减券，使用后当前价格直接减去 `value`（正整数）。
    - `type = 1`：折扣券，使用后当前价格变为 $\lfloor \text{当前价格} \times \text{value} / 100 \rfloor$，即向下取整。
    - **注意**：应用一张优惠券后，新的价格将作为后续优惠券的基准。
#### 输入
- 第一行三个整数 $n, m, k$（$1 \le n \le 10,\ 0 \le m \le 10,\ 0 \le k \le 5$）
- 第二行 $n$ 个整数，表示必须买的商品价格（每个价格 $\le 1000$）
- 第三行 $m$ 个整数，表示可选商品的价格（每个价格 $\le 1000$），若 $m=0$，则没有此行输入
- 接下来 $k$ 行，每行描述一张优惠券，格式为：`type threshold value`
    - `type` 为 0 或 1
    - `threshold` 和 `value` 均为正整数（对于折扣券，`value` 表示折扣率，如 90 表示 9 折）
#### 输出
- 输出一个整数，表示最少实际支付金额。

```java
import java.util.*;

public class Main {
    static class Coupon {
        int type, threshold, value;
        Coupon(int t, int th, int v) {
            type = t;
            threshold = th;
            value = v;
        }
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int m = sc.nextInt();
        int k = sc.nextInt();
        
        // 计算必买商品总价
        int mustSum = 0;
        for (int i = 0; i < n; i++) {
            mustSum += sc.nextInt();
        }
        
        // 读取可选商品
        int[] opt = new int[m];
        for (int i = 0; i < m; i++) {
            opt[i] = sc.nextInt();
        }
        
        // 读取优惠券
        Coupon[] cps = new Coupon[k];
        for (int i = 0; i < k; i++) {
            int t = sc.nextInt();
            int th = sc.nextInt();
            int v = sc.nextInt();
            cps[i] = new Coupon(t, th, v);
        } 
        
        int ans = Integer.MAX_VALUE;
        // 枚举所有可选商品组合
        for (int mask = 0; mask < (1 << m); mask++) {
            int total = mustSum;
            for (int i = 0; i < m; i++) {
                if ((mask & (1 << i)) != 0) {
                    total += opt[i];
                }
            }
            
            // 枚举所有优惠券使用排列
            List<Integer> perm = new ArrayList<>();
            for (int i = 0; i < k; i++) perm.add(i);
            do {
                int cur = total;
                boolean[] used = new boolean[k];
                for (int idx : perm) {
                    if (used[idx]) continue;
                    Coupon c = cps[idx];
                    if (cur >= c.threshold) { // 满足门槛才可以使用
                        used[idx] = true;
                        if (c.type == 0) { // 满减券
                            cur -= c.value;
                        } else { // 折扣券，向下取整
                            cur = (cur * c.value) / 100;
                        }
                    }
                }
                // 支付金额不能为负数
                cur = Math.max(cur, 0);
                if (cur < ans) ans = cur;
            } while (nextPermutation(perm));
        }
        System.out.println(ans);
    }

    // 生成下一个排列的工具方法
    private static boolean nextPermutation(List<Integer> arr) {
        int n = arr.size();
        int i = n - 2;
        while (i >= 0 && arr.get(i) >= arr.get(i+1)) i--;
        if (i < 0) return false;
        int j = n - 1;
        while (arr.get(j) <= arr.get(i)) j--;
        Collections.swap(arr, i, j);
        Collections.reverse(arr.subList(i+1, n));
        return true;
    }
}
```



### 2、病毒扩散模拟
作为健康防护应用的开发者，你需要模拟病毒在矩形房间内的扩散过程。房间用二维网格表示，网格中：
- `0` 代表健康人员
- `1` 代表已感染人员
- `x` 代表障碍物（如隔断、墙壁）
病毒每轮通过上下左右相邻的格子传播，每轮传播耗时 1 小时。要求计算病毒传播到所有可被感染人员所需的最少时间。若存在无法被感染的健康人员（被障碍物隔离），则返回 `-1`。
#### 输入
- 第一行：二维网格的行数 $m$ 和列数 $n$，中间用空格隔开（$1 \le m \le 100, 1 \le n \le 100$）。
- 后面 $m$ 行：每行包含具体的健康人员、已感染人员、障碍物情况，中间用空格隔开。
#### 输出
- 要求计算病毒传播到所有可被感染人员所需的最少时间。若存在无法被感染的健康人员（被障碍物隔离），则返回 `-1`。


```java
import java.util.LinkedList;
import java.util.Queue;
import java.util.Scanner;

public class Main {
    // 上下左右四个方向
    private static final int[][] dirs = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int m = sc.nextInt();
        int n = sc.nextInt();
        sc.nextLine(); // 读取换行符

        String[][] grid = new String[m][n];
        Queue<int[]> queue = new LinkedList<>();
        int totalHealth = 0; // 统计所有健康人员总数

        // 初始化网格，收集初始感染点，统计健康人数
        for (int i = 0; i < m; i++) {
            String[] parts = sc.nextLine().trim().split(" ");
            for (int j = 0; j < n; j++) {
                grid[i][j] = parts[j];
                if ("1".equals(grid[i][j])) {
                    queue.offer(new int[]{i, j});
                } else if ("0".equals(grid[i][j])) {
                    totalHealth++;
                }
            }
        }

        // 特殊情况：一开始就没有健康人员，直接返回0
        if (totalHealth == 0) {
            System.out.println(0);
            return;
        }

        int time = 0;
        // 多源BFS层序遍历
        while (!queue.isEmpty()) {
            int size = queue.size();
            boolean infected = false; // 标记当前轮次是否有新感染
            for (int i = 0; i < size; i++) {
                int[] curr = queue.poll();
                int x = curr[0], y = curr[1];
                // 遍历四个相邻方向
                for (int[] dir : dirs) {
                    int nx = x + dir[0];
                    int ny = y + dir[1];
                    // 判断坐标合法性，且当前位置是健康人员
                    if (nx >= 0 && nx < m && ny >=0 && ny <n && "0".equals(grid[nx][ny])) {
                        grid[nx][ny] = "1"; // 标记为已感染
                        totalHealth--;
                        queue.offer(new int[]{nx, ny});
                        infected = true;
                    }
                }
            }
            // 如果当前轮有新感染，时间+1
            if (infected) {
                time++;
            }
        }

        // 还有未被感染的健康人员，返回-1，否则返回总时间
        System.out.println(totalHealth == 0 ? time : -1);
    }
}
```


# 3、爆破任务-多规格炸弹

云小核接到一个爆破任务，为了重建老旧一条街，需要将这条街上的老建筑全部爆破。云小核拿到一张图，显示了这条街上每个建筑的位置。还拿到了很多炸弹，这些炸弹只能部署在建筑里，且具有一定的规格/影响范围。不同规格的炸弹，影响范围不同，每个炸弹消耗的资源等于其影响范围。距离炸弹部署点距离小于等于这些炸弹影响范围的，会被一起爆破。由于预算有限，请你帮云小核计算至少需要多少资源，才能将所有建筑爆破。
如下图所示，完成任务所需的最小资源消耗为 35：
- 炸弹规格：15，20，40
- 建筑位置：0，20，80
- 在位置 0 部署规格为 20 的炸弹，位置 20 可同时被覆盖；
- 在位置 80 部署规格为 15 的炸弹；
- 此部署方法消耗的资源最小，为 $20 + 15 = 35$
#### 输入
- 第 1 行：两个整型数值 $N, M$（$1 \le N \le 100$ 表示建筑数量，$1 \le M \le 10$ 表示炸弹规格数）
- 第 2 行：$N$ 个不同的整型数值：$n_1, n_2, \dots, n_N$（$0 \le n_i \le 10^9$ 表示建筑的位置）
- 第 3 行：$M$ 个不同的整型数值：$m_1, m_2, \dots, m_M$（$1 \le m_i \le 10^9$ 表示不同规格炸弹的影响范围）
 #### 输出
- 一个整型数值，表示所需的最小资源消耗。
```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int N = sc.nextInt();
        int M = sc.nextInt();
        long[] pos = new long[N];
        for (int i = 0; i < N; i++) {
            pos[i] = sc.nextLong();
        }
        // 对建筑位置排序
        Arrays.sort(pos);
        List<Long> bombList = new ArrayList<>();
        for (int i = 0; i < M; i++) {
            bombList.add(sc.nextLong());
        }
        // 对炸弹范围排序，去除性价比低的炸弹：范围小但消耗高的直接丢弃
        Collections.sort(bombList);
        List<Long> validBombs = new ArrayList<>();
        long minCost = Long.MAX_VALUE;
        for (int i = bombList.size() - 1; i >= 0; i--) {
            long r = bombList.get(i);
            if (r < minCost) {
                validBombs.add(r);
                minCost = r;
            }
        }
        Collections.reverse(validBombs);
        
        long[] dp = new long[N + 1];
        Arrays.fill(dp, Long.MAX_VALUE / 2); // 除2防止加法溢出
        dp[0] = 0;
        for (int i = 1; i <= N; i++) {
            // 当前要覆盖的最右建筑是pos[i-1]，炸弹放在这里
            long rightPos = pos[i-1];
            for (long r : validBombs) {
                long leftCover = rightPos - r;
                // 二分找第一个>=leftCover的建筑位置
                int j = Arrays.binarySearch(pos, leftCover);
                if (j < 0) {
                    j = -j - 1;
                }
                // 从j到i-1的建筑都被这个炸弹覆盖，转移状态
                if (dp[j] + r < dp[i]) {
                    dp[i] = dp[j] + r;
                }
            }
        }
        System.out.println(dp[N]);
    }
}
```
