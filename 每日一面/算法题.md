## 题目 1：深海潜艇能量探险（简化版）

### 题目描述（简化）

- 潜艇有初始能量 `m`
- 有 `n` 个危险区域，每个区域 `(a_i, b_i)`：
    - 穿越消耗能量 `a_i`
    - 穿越完成后补充能量 `b_i`
- 穿越过程中能量必须 **> 0**
- 可以自由安排穿越顺序

**目标**：判断是否存在一个顺序，使潜艇成功穿越所有区域

### 输入示例

```
n ma0 b0a1 b1...an-1 bn-1
```

### 简化抽象

- 每个区域看作 `(消耗, 补充)`
- 能量模拟：`E -= a_i; if E <= 0 fail; E += b_i`
- 核心问题：寻找一种顺序使能量始终 > 0

### 解题思路（抽象）

1. **分组启发**：
    - 安全区：`b_i >= a_i` → 穿越后增加能量
    - 危险区：`b_i < a_i` → 可能减少能量
2. **排序/贪心模拟**：
    - 安全区按消耗 `a_i` 升序优先穿越
    - 危险区按 `(a_i - b_i)` 降序处理（最危险先穿）

> [!NOTE] 排序：
>List<int[]>dangerList = new ArrayList<>();
>List<int []>safeList = new ArrayList<>(); 
> safeList.sort((o1, o2) -> o1[0] - o2[0]);
> dangerList.sort((o1, o2) -> (o2[0] - o2[1]) - (o1[0] - o1[1]));

1. **模拟**：
    - 从初始能量开始，依次穿越区域
    - 每步检查能量 > 0
    - 如果能走完所有区域 → 成功

> **重点**：不能只按安全/危险分类，还要考虑顺序可能需要穿插，以保证能量累积。

## 题目 2：分布式任务负载均衡（简化版）

### 题目描述（简化）

- 有 `N` 个任务，`M` 个节点
- 任务按 ID 顺序 `[0..N-1]`
- 分配规则：
    1. 顺序性：节点 i 的任务 ID < 节点 j 的任务 ID（i < j）
    2. 连续性：每个节点任务连续
    3. 原子性：单个任务不可拆分
- 任务负载 `C[i]`
- 负载最高节点记为 `X`
- 目标：**最小化 X**

### 输入示例

```
N MC0 C1 ... CN-1
```

### 简化抽象

- 将问题看作 **数组 `[C0..CN-1]` 切成 M 段**
- 每段对应一个节点
- **目标**：最小化最大段和

### 解题思路（抽象）

1. **确定二分区间**：
    - 左边界：`max(C[i])`
    - 右边界：`sum(C[i])`
2. **二分 + 可行性检查**：
    - 给定 X（最大允许负载）
    - 从左到右贪心分配任务到节点：
        - 当前节点累加任务
        - 超过 X → 新开一个节点
    - 节点总数 ≤ M → 可行
3. **二分搜索**：
    - 收敛到最小可行 X → 最优负载

> **重点**：不需要生成具体分配方案，只关心最小化最大负载
