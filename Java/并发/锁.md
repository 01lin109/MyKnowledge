## 1. 锁重入（Reentrant）—— 锁的“自己人免检通道”

- **属于什么**：锁的基本特性。
    
- **大白话**：同一个线程，拿到了外层方法的锁之后，**可以直接进入内层同样需要这把锁的方法**，不需要重新排队死锁。
    
```java
public synchronized void methodA() {
    System.out.println("进入了A方法");
    methodB(); // 注意：methodB 也是 synchronized 的
}

public synchronized void methodB() {
    System.out.println("进入了B方法");
}
```

- **如果没有锁重入**：线程执行到 `methodA` 锁住了对象，接着调用 `methodB`。发现 `methodB` 也需要这把锁，于是线程开始等待锁释放。但锁在自己手里，方法没执行完绝不释放——**自己把自己锁死，直接死锁**。
    
- **底层的实现**：JVM 怎么知道是自己人？它在锁对象头里维护了一个 **计数器（counter）** 和一个 **持有者线程指针**。
    
    1. 线程第一次抢到锁，计数器变成 1。
        
    2. 发现又是这个线程来拿锁，计数器直接 $+1$ 变成 2（顺利通过）。
        
    3. 方法执行完退出，计数器 $-1$。当计数器清零时，锁才真正释放。
        

## 2. 自旋锁（Spin Lock）—— 锁的“疯狂原地试探”

- **属于什么**：锁的优化手段（减少线程上下文切换）。
    
- **大白话**：当线程去抢锁失败时，**它不立刻进入阻塞状态（不躺平）**，而是在原地执行一段无意义的循环（比如循环 10 次），看看持锁的线程是不是马上就释放了。
    
- **为什么要自旋**：线程挂起和唤醒（从用户态切换到内核态）是非常昂贵的性能开销。JVM 发现，很多锁被占用的时间其实极短。与其让你睡过去再叫醒你，不如让你在原地“多眨几眼眼”，说不定持锁线程一抬脚就走了，你直接就能拿到锁。
    
- **代价**：自旋是要白白消耗 CPU 的。如果对方占着锁很久不放，你一直在原地疯狂自旋，CPU 就会被你飙到 100%。所以 Java 后来引入了**自适应自旋锁**（根据上一次自旋成不成功，来决定这次自旋多少次，非常智能）。
    

## 3. 锁升级（Lock Inflation）—— `synchronized` 的四个形态

- **属于什么**：JVM 对 `synchronized` 关键字的极致性能优化。
    
- **大白话**：JVM 为了防止一上来就用重量级锁，设计了一套根据竞争激烈程度，自动给锁“加码”的机制。
    

锁升级是**单向不可逆**的，它的四个状态长这样：

$$\text{无锁} \longrightarrow \text{偏向锁} \longrightarrow \text{轻量级锁} \longrightarrow \text{重量级锁}$$

### ① 偏向锁（Biased Lock）

- **场景**：这段代码从头到尾其实**只有一个线程**在反复执行（90% 的生产场景都是这样）。
    
- **操作**：锁会在对象头里记下这个线程的 ID。下次这个线程再来，一看 ID 是自己，直接进去，连 CAS 操作都不做。这把锁“偏心”眼它。
    

### ② 轻量级锁（Lightweight Lock）

- **场景**：出现了另一个线程来竞争，变成了**两个线程交替执行**（有竞争，但很轻微，没有冲突）。
    
- **操作**：偏向锁升级为轻量级锁。线程尝试通过 **CAS** 去修改对象头里的锁记录。如果偶尔冲突，就用**自旋**在原地等一等。
    

### ③ 重量级锁（Heavyweight Lock）

- **场景**：高并发爆发，**大量线程疯狂同时抢锁**，或者某个线程自旋到头了对方还没放锁。
    
- **操作**：对不起，顶不输了。自旋没用了，锁直接升级为重量级锁。JVM 退出舞台，向操作系统申请内核锁（Monitor）。所有没抢到锁的线程全部**挂起、进入阻塞队列**，等待操作系统调度。
    

## 总结：它们是怎么串联起来的？

我们用一个故事把这三个东西全串起来：

你（**线程A**）去上一个公共厕所（**执行同步代码块**）：

1. 厕所没人，你在门上贴了你的名字（**偏向锁**），进去上厕所。出来后名字没擦掉。下次你再来，一看名字是自己，直接进（**锁重入**，计数器 $+1$）。
    
2. 这次你来，发现门上名字被擦了，有个兄弟在里面。你不想去排队躺平，于是在门口隔 2 秒敲一次门（**自旋锁**）。
    
3. 这时，外面突然来了 50 个人都要上厕所（高并发竞争）。
    
4. 场面失控，为了防止大家把门拆了，居委会大妈（JVM）直接装了一把高科技密码锁（**升级为重量级锁**），把除里面那个人以外的 50 个人全部赶到外面的休息室挂起排队（**线程阻塞**）。
